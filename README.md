# Procesador de Imágenes en Java

Aplicación con interfaz gráfica (Swing) diseñada para la manipulación y procesamiento de archivos de imagen. Este proyecto demuestra el manejo de flujos de datos (I/O), renderizado de gráficos y gestión de eventos en Java.

## ✨ Características
- Interfaz intuitiva para carga y visualización de imágenes.
- Procesamiento de filtros y transformaciones básicas.
- Gestión de archivos mediante `JFileChooser`.

## 🛠️ Tecnologías
- **Lenguaje:** Java 17+
- **Librerías:** Java AWT, Swing.
- **Entorno:** CachyOS (Arch Linux) / IntelliJ IDEA.

## 📋 Uso
1. Clonar: `git clone git@github.com:Helminth117/procesador-imagenes-java.git`
2. Compilar y ejecutar `ProcesadorImagenes.java` desde cualquier IDE compatible con Java.
