<h1 align="center">Procesador de Imágenes</h1>

<p align="center">Filtros de imagen e histogramas RGB con una interfaz en Java Swing.</p>

<p align="center">
  <img src="https://img.shields.io/badge/Java-17%2B-2B2B2B?style=flat-square&labelColor=0D0D0D&logoColor=F5F5F5&logo=openjdk" alt="Java 17+">
  <img src="https://img.shields.io/badge/Swing-0D0D0D?style=flat-square&labelColor=0D0D0D&logoColor=F5F5F5" alt="Swing">
</p>

Un solo archivo, sin dependencias. Se carga una imagen con el botón o arrastrándola a la ventana y se
le aplican filtros o se analizan sus colores.

| Sección | Qué hay |
|---|---|
| Filtros | Original, escala de grises, negativo y negativo en grises |
| Análisis | Histogramas de rojo, verde, azul y RGB combinado; tabla de frecuencias |
| Exportar | Guardar la imagen con el filtro aplicado |

## Ejecutar

```bash
java ProcesadorImagenes.java
```
